# media-dler

從任何 app「**分享**」一個連結或影音檔過來，media-dler 就能：

- **下載**影片 / 圖片 / 音訊 — 以 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 為引擎，涵蓋 YouTube、Instagram、TikTok、Threads、X / Twitter、Facebook、Reddit、Bilibili… 等 1000+ 平台。
- **轉成逐字稿**（語音轉文字）— 裝置端離線或雲端，多語自動偵測、中文自動轉台灣正體。
- **取出純音檔** — 從影片無損抽出原音軌存成音檔。

![build](https://github.com/changyow-ai/media-dler/actions/workflows/build.yml/badge.svg)

- **平台**：Android 9（API 28）以上

## 功能

### 下載

- **分享即下載**：在任意 app 點「分享 → media-dler」，或對選取文字用「處理文字」；也可複製連結後在首頁按「貼上連結」。
- **一般來源兩種模式**（設定可切）：**一鍵**直接用預設值下載；**彈窗**逐項選畫質 / 音訊 / 圖片再下載。
- **多媒體勾選**：IG 輪播、多圖貼文等含多個項目時可勾選要下載哪些。
- **台灣蝦皮商品**：支援商品網址與 `tw.shp.ee` 分享連結，從商品公開的初始資料取得圖片與影片；不開啟登入頁面、不匯入瀏覽器帳號。
- **劇集播放頁**：支援部分公開來源提供的直接 HLS / MP4 線路與播放器 iframe，保留原始分享網址、劇名、集數及下載所需標頭；未提供直接影片的線路會提示改選其他線路。
- **劇集自動排程**：分享支援來源的單集播放頁後，直接依預設畫質加入排程，逐筆下載。
- **8maple 廣告略過**：受支援的未加密 TS 劇集，先以 discontinuity 邊界找候選區間，再核對已確認的完整影音內容，命中才在下載成品略過；標記、時長或解析度本身不會觸發刪除。候選片段仍需下載驗證，遵循下載限速，保留的片段會重用快取。重試沿用已固定的判斷結果，辨識版本或來源改變時使用獨立續傳紀錄。目前 HLS 指紋涵蓋三個已驗證編碼版本（288588 一種、451451 兩種），不同素材或重新編碼可能無法辨識；未知或不支援的內容會保留。MP4 儲存前另以原有完整內容指紋處理已知廣告，無損移除並驗證保留影音。進度顯示略過／移除段數，不會改動先前已下載的影片。
- **去 AD 設定**：預設開啟，只執行已知完整影音指紋的快速確認；來源標記、discontinuity、時長或解析度本身不會觸發刪除。可關閉全部去 AD，或另行開啟權重分析（預設關閉）。選項在任務建立時保存，之後修改設定不影響既有排程、暫停或重試；無法確認策略的舊暫存會保留並提示重新建立下載，不會改剪既有成品。
- **廣告分析與略過**：分析期間，下載項目與通知顯示「廣告分析中」，項目按鈕及選單提供「略過分析」。按下後會停止該任務的廣告分析，改下載包含廣告的完整原始影片；此選擇會隨該任務保存，重試或重開 App 後仍有效。完整影片使用獨立的續傳／恢復紀錄，避免沿用已去廣告的成品。進入實際影音下載後顯示「下載中」，按鈕恢復一般暫停功能。
- **多訊號廣告辨識（實驗性，可選）**：Gimy 與 8maple 的完整、未加密 TS HLS 可由手機分析 discontinuity 區間及相鄰區間，對畫面銜接、音量、文字及版面加權；中文 OCR 模型隨 App 附帶。沿用實驗 V3 的權重與 55 分門檻，不要求特定品牌、網址或任一訊號必須出現。判斷先固定再下載保留片段，略過後須通過完整影音解碼、時間戳及時長驗證才儲存；無法判讀的候選保留。分析顯示候選已處理數、未確認數、階段與累計耗時。全候選掃描可能讀取接近全片，快取與續傳會重用這些片段；權重分析仍可能誤判且耗時較久，請依實機結果評估。
- **下載期間驗證**：已略過廣告的 TS HLS 影片，下載時累積 30 秒媒體、12 個片段或 8 MiB，任一到達即由背景解碼器處理；同一解碼器持續保留跨片段前後文，最後不足一批也會處理。完成後仍檢查成品軌道、時長、時間戳與內容一致性，核對成功可省去重複全片解碼；證據不足、內容或播放時序不一致、音訊輸出及不支援內容，沿用完成後的完整驗證。取消會收尾原驗證程序，續傳從本機前綴重建解碼狀態。這是減少下載後等待的批次起始設定，尚未宣稱為各手機的最佳效能參數。
- **權重 OCR 取樣**：App 每個候選固定辨識前段 5% 與 10% 位置的兩張圖片，不取中後段，保留前後文各一張作比較；OCR 圖片寬度最多 960px，保持比例且不放大小圖。相較前段單張，兩張會增加 OCR 工作，也仍可能漏掉稍後才出現的小字、廣告或節目字幕。計分維持原本三張的基準，證據覆蓋最多為三分之二；若兩個位置對應同一實際畫格／時間，只計一次，診斷記錄分開呈現取樣設定與證據覆蓋。完成必要影音驗證後，若影音分數加上文字可能貢獻的最高分仍達不到門檻，直接保留並略過候選 OCR；兩張的文字與版面合計內容貢獻上界為 50 分，因此只有影音分數嚴格低於 5 分且通過數值裕量檢查時能略過，前後文 OCR 維持原行為。此時記錄分數上界、略過原因及不完整的 OCR 證據，不將部分分數當成完整分數。手機只計算權重判斷需要的畫面統計，省略的診斷另有標記；獨立的 host 實驗工具維持原本完整統計及三張／1920px 預設。
- **影片首頁選集**：支援的劇集首頁按播放線路分頁，可在同一線路複選集數。翻頁保留選擇，勾選其他線路才清空原選擇；提交後依集數排序，輪到該集時才解析影片。
- **持久下載任務**：重開 app 後恢復未完成佇列及可續傳暫存；支援來源的單集分享先保存播放頁，輪到下載時才解析最新串流。
- **暫停與繼續**：下載項目的暫停按鈕或選單可暫停單一任務，保存進度並讓後面的任務繼續。按「繼續下載」回到原排程位置；支援續傳的來源沿用原串流與暫存，不支援時會提示重新下載。手動暫停會保留至下次開啟 App，不會因網路恢復或「繼續排程」而自動解除。
- **立即下載**：在排隊或已暫停項目的選單按「立即下載」，可將它放到第一順位。目前下載安全停止後排到第二，其餘相對順序不變；優先項目結束後再接續原下載。已進入處理／儲存的檔案會先完成，再開始優先項目。
- **HLS 片段續傳**：可確認內容相同的未加密劇集串流，支援單層分段清單及單一畫質的主清單；中斷後先截回上一個完整片段再重抓，避免尾端不完整或重複。舊版暫存缺少片段邊界紀錄，需由新版建立續傳點後生效；引擎更新後若尚未驗證續傳相容性，會保留暫存並提示更新 app。
- **網路中斷自動接續**：支援片段續傳的媒體下載遇到短暫 DNS 或連線錯誤時，會依序等待 5、15、30、60 秒，使用同一份片段紀錄重試。錯誤發生後，只有裝置目前確實離線才保存任務、暫停整個佇列並顯示「等待網路恢復」；裝置仍有網路而單一來源失敗時，顯示該項的來源錯誤並繼續後面的排程。404／410 才提示影片不存在或連結失效，拒絕存取與憑證錯誤會顯示各自原因，可從項目選單查看完整失敗原因。恢復連線後自動排程接續，程序被系統回收或手機重開後也可透過 WorkManager 恢復。Android 12 以上的背景恢復會保留有效串流與續傳點，分次執行；無法續傳的下載，或封裝、轉檔時間過長時，提示開啟 App 繼續。重新開啟 App 時，已下載完成而尚未儲存的媒體可先離線恢復儲存。系統可能延後背景執行；空間不足與系統明確暫停仍需手動繼續，強制停止 App 後需重新開啟。串流網址或播放清單改變時，無法確認內容一致的暫存不會接續，以免接錯影片。
- **下載速限**：在「設定 → 下載速限」選擇不限速、256 KB/s 起的常用速度或自訂 KB/s／MB/s。預設不限速，變更套用至下一次開始或重試的媒體下載，進行中的任務維持原速限；調整速限不會清除續傳暫存。
- **格式選擇**：最佳畫質、限制解析度（1080p / 720p / 480p / 360p）、音訊轉 **MP3 / M4A**、圖片原檔。
- **儲存位置**：Android 10 以上預設公開的 `Download/media-dler/`（相簿 / 檔案 app 可見），或用 SAF 指定資料夾；Android 9 需先在設定選擇儲存資料夾，建議 `Download/media-dler/`。開始下載前檢查資料夾是否可用，儲存時再次確認。
- **劇集整理**：支援來源的劇集存到目前儲存目錄下的 `drama/`，依已知劇名、季數與集數整理；一般來源沿用原目錄。
- **下載歷史**與**前景進度通知**：可取消、重試，下載頁提供「重試全部失敗」一次重新排程，完成可點開檔案；來源沒縮圖時自動抽一張影格當預覽。系統暫停後開啟 app 可恢復，空間不足時釋放空間後按「繼續排程」。
- **鎖屏背景下載**：下載期間由前景 Service 持有 CPU 喚醒鎖，並在 Android 9 / 11 等較舊系統持有 Wi-Fi 鎖；喚醒鎖持續續約，沒有 30 分鐘的下載時限，佇列結束或暫停後釋放。程序被系統回收時，允許系統重建 Service，由保存的佇列恢復未完成下載。
- **背景下載設定**：在「設定 → 背景下載」查看並申請排除系統電池最佳化，減少未插電、熄屏休眠時的網路與 CPU 限制；是否核准由系統設定決定。
- **任務選單**：可複製來源連結、手動選格式或轉文字；尚未開始或已結束的劇集可修正記錄資訊，已建立的檔案不會搬動。
- **引擎線上更新**：yt-dlp 可在 app 內更新，平台改版時不必重裝。

廣告判斷、OCR 計分、續傳與成品驗證的完整流程及限制，見 [廣告處理實作說明](doc/ad-processing.md)。

### 語音轉文字（逐字稿）

- **三種來源**：分享本機**影片 / 聲音檔**、分享**影片連結**（自動取音訊轉錄）、或有字幕的 **YouTube**（直接抓字幕、秒出，跳過辨識）。
- **兩種引擎**（設定可切）：
  - **裝置端（預設）**：whisper.cpp，**完全離線、免金鑰、隱私**；可選 `base`（快）/ `small`（較準）模型，首次使用時下載。
  - **雲端**：OpenRouter（**自備 API 金鑰**），速度與中文準度更佳。
- **語言**：多語自動偵測，中文自動轉**台灣正體**；可在設定**鎖定主要語言**，避免無人聲片頭被誤判。
- **背景進行**：通知顯示進度、可中止，中斷後重新開啟 app 可由斷點接續；完成後可**複製 / 分享**，結果頁標示這次用的引擎與模型，並有「**轉錄記錄**」清單。

### 取出聲音

- 分享**影片**時選「**取出聲音**」，會**無損**抽出原音軌存成 `.m4a`（保留原音質、不重新編碼），存到你的下載位置。

### 區網分享（UPnP / SFTP）

- 在「設定 → 區網分享」分別開啟 **UPnP／DLNA** 與 **SFTP**。分享目前下載資料夾及子目錄；切換儲存位置會重新啟動分享。
- **UPnP／DLNA**：同區網播放器可找到 `media-dler`、瀏覽影音與圖片、直接串流及快轉；依播放器支援的原始格式播放，沒有轉碼。
- **SFTP**：先儲存帳號、密碼與連接埠（預設 `2222`），再依畫面上的位址連線。提供列目錄、讀檔與續傳，唯讀且不提供 SSH shell。
- 不需要開著 Kodi 或停留在 app 畫面。分享使用獨立前景服務，通知列可一鍵停止；手機重新開機後預設關閉。
- **閒置自動關閉**：預設連續 1 小時沒有讀取檔案便停止 UPnP 與 SFTP，下拉選單可選 30 分鐘、1 小時、2 小時或永不，每 60 秒檢查一次。兩種分享共用計時，實際讀取檔案（含串流、Range 與續傳）會重新計時；搜尋裝置、瀏覽目錄、登入與保持連線不會。重新開啟分享或變更閒置設定會重新計時，網路重連不會。到期後釋放分享的 CPU／Wi-Fi 鎖與多播鎖，需要使用時可再手動開啟。
- **分享自動保活**：啟用分享即由前景服務持有 CPU／Wi-Fi 鎖，系統回收程序後可重建服務、恢復原先啟用的分享；手動停止及閒置逾時會清除恢復狀態並釋放鎖。重建沿用最近讀檔期限，讀取紀錄最多每 60 秒存一次，僅在程序回收後有最多 60 秒的恢復寬限，重複重建不累加。原 TCP 連線仍會隨程序死亡中斷，客戶端需重新連線或續傳。手機重新開機不自動分享；系統強制停止或廠商禁止背景執行時仍可能需要重新開啟 app。
- 預設下載位置只列出 Android 允許本 app 讀取的 MediaStore 檔案；要分享其他來源或重新安裝前留下的檔案，請以 SAF 授權該資料夾。
- 只分享已完成的檔案，忽略下載暫存；直接讀取現有資料夾，不依賴下載歷史，也不建立媒體索引或複製影片。SAF 位置需支援隨機讀取，建議本機資料夾。
- 使用同一個 Wi-Fi 或乙太網路（IPv4）；訪客網路、用戶端隔離或封鎖多播可能讓播放器找不到伺服器。UPnP 沒有帳密，開啟期間同區網裝置可讀取分享內容；SFTP 需登入。
- 分享期間會耗電，系統或廠商的省電限制仍可能停止服務。SFTP 密碼僅保存加鹽雜湊，主機金鑰保存在 app 私有且不備份的目錄。

實際連線驗證：

```sh
python -m pip install paramiko
python scripts/check-sharing.py --root /tmp/media-dler-sharing --prepare
./gradlew :core:sharingSmokeServer -PshareRoot=/tmp/media-dler-sharing
# 在另一個終端機，使用上一步印出的 HTTP 連接埠：
python scripts/check-sharing.py --root /tmp/media-dler-sharing --http <port> --ssdp
```

這套檢查會真的連線測 SSDP、SOAP、事件訂閱、HTTP Range、SFTP 登入與唯讀限制，包含中文檔名及超過 4 GiB 的位移。Android 的儲存與服務測試可在可用 Wi-Fi 的測試裝置／模擬器執行 `./gradlew :app:connectedDebugAndroidTest`；會改寫測試裝置的 SFTP 登入設定，請使用專用測試環境。若要驗證 SAF，先在 app 授權本機資料夾，再加上 `-Pandroid.testInstrumentationRunnerArguments.treeUri=<tree URI>`。

已安裝 FFmpeg 的環境可在建立測試檔與連線檢查兩個指令都加上 `--playback`，實際串流、跳轉並解碼 H.264 影片。

## 使用

1. **下載**：在任一 app 點分享 → media-dler；一般來源依設定使用一鍵或彈窗模式，支援來源的劇集播放頁直接加入排程。
2. **選集**：分享支援的劇集首頁，選擇同一線路的集數後按「**加入排程**」。
3. **轉逐字稿**：分享影片 / 聲音檔 → 選「**轉成文字**」；分享連結後可選「**轉文字**」，也可從下載任務選單啟動。
4. **取出聲音**：分享影片 → 選「**取出聲音**」。
5. 設定裡可切換轉錄引擎 / 語言 / 模型，雲端金鑰也在設定貼上。

## 注意與限制

- **平台支援度取決於 yt-dlp**：下載失敗先更新引擎（設定 → 下載引擎 → 更新 yt-dlp），YouTube 尤其常需更新。Threads 影片可下載，**純圖 / 多圖貼文不支援**；IG / FB 私人貼文等需登入，目前僅支援公開內容。
- **雲端轉錄需自備金鑰**：在設定貼上你的 OpenRouter 金鑰（**只存在裝置本機，不內建於 app、不隨版散布**）。按音訊**時長**計費，建議用 `openai/whisper-large-v3-turbo`（最便宜也最穩定）。
- **裝置端模型首次需下載**（`base` ~142MB / `small` ~466MB），非 Wi-Fi 會先詢問；中階手機上 `small` 可能慢於即時，中文準度低於雲端。
- 下載總量未知時顯示已下載量或片段數；封裝與儲存以處理階段顯示。
- **未插電熄屏下載**：請先在「設定 → 背景下載」允許排除電池最佳化；部分手機另有 app 背景執行限制，需在系統電池設定調整。排除最佳化不代表程序不會被系統停止；Android 15 以上仍有背景資料同步服務的時間限制，中斷後可開啟 app 恢復排程。
- 請尊重各平台服務條款與著作權，只下載 / 轉錄你有權保存的內容。
