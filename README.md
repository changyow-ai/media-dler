# media-dler

從任何 app「**分享**」一個連結或影音檔過來，media-dler 就能：

- **下載**影片 / 圖片 / 音訊 — 以 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 為引擎，涵蓋 YouTube、Instagram、TikTok、Threads、X / Twitter、Facebook、Reddit、Bilibili… 等 1000+ 平台。
- **轉成逐字稿**（語音轉文字）— 裝置端離線或雲端，多語自動偵測、中文自動轉台灣正體。
- **取出純音檔** — 從影片無損抽出原音軌存成音檔。

![build](https://github.com/changyow-ai/media-dler/actions/workflows/build.yml/badge.svg)

- **平台**：Android 9（API 28）以上

## 功能

### 下載

- **分享即下載**：在任意 app 點「分享 → media-dler」，或對選取文字用「處理文字」；也可複製連結後在首頁按「貼上連結」。
- **一般來源兩種模式**（設定可切）：**一鍵**直接用預設值下載；**彈窗**逐項選畫質 / 音訊 / 圖片再下載。
- **多媒體勾選**：IG 輪播、多圖貼文等含多個項目時可勾選要下載哪些。
- **台灣蝦皮商品**：支援商品網址與 `tw.shp.ee` 分享連結，從商品公開的初始資料取得圖片與影片；不開啟登入頁面、不匯入瀏覽器帳號。
- **劇集播放頁**：支援部分公開來源提供的直接 HLS / MP4 線路與播放器 iframe，保留原始分享網址、劇名、集數及下載所需標頭；未提供直接影片的線路會提示改選其他線路。
- **劇集自動排程**：分享支援來源的單集播放頁後，直接依預設畫質加入排程，逐筆下載。
- **影片首頁選集**：支援的劇集首頁按播放線路分頁，可在同一線路複選集數。翻頁保留選擇，勾選其他線路才清空原選擇；提交後依集數排序，輪到該集時才解析影片。
- **持久下載任務**：重開 app 後恢復未完成佇列及可續傳暫存；支援來源的單集分享先保存播放頁，輪到下載時才解析最新串流。
- **HLS 片段續傳**：可確認內容相同的未加密劇集串流，支援單層分段清單及單一畫質的主清單；中斷後先截回上一個完整片段再重抓，避免尾端不完整或重複。舊版暫存缺少片段邊界紀錄，需由新版建立續傳點後生效；引擎更新後若尚未驗證續傳相容性，會保留暫存並提示更新 app。
- **網路中斷自動接續**：支援片段續傳的任務開始下載後，若遇到短暫 DNS 或連線錯誤，會依序等待 5、15、30、60 秒，自動使用同一份片段紀錄重試；仍失敗時保留任務供稍後重試。
- **格式選擇**：最佳畫質、限制解析度（1080p / 720p / 480p / 360p）、音訊轉 **MP3 / M4A**、圖片原檔。
- **儲存位置**：Android 10 以上預設公開的 `Download/media-dler/`（相簿 / 檔案 app 可見），或用 SAF 指定資料夾；Android 9 需先在設定選擇儲存資料夾，建議 `Download/media-dler/`。開始下載前檢查資料夾是否可用，儲存時再次確認。
- **劇集整理**：支援來源的劇集存到目前儲存目錄下的 `drama/`，依已知劇名、季數與集數整理；一般來源沿用原目錄。
- **下載歷史**與**前景進度通知**：可取消、重試，完成可點開檔案；來源沒縮圖時自動抽一張影格當預覽。系統暫停後開啟 app 可恢復，空間不足時釋放空間後按「繼續排程」。
- **鎖屏背景下載**：下載期間由前景 Service 持有 CPU 喚醒鎖，並在 Android 9 / 11 等較舊系統持有 Wi-Fi 鎖；喚醒鎖持續續約，沒有 30 分鐘的下載時限，佇列結束或暫停後釋放。程序被系統回收時，允許系統重建 Service，由保存的佇列恢復未完成下載。
- **背景下載設定**：在「設定 → 背景下載」查看並申請排除系統電池最佳化，減少未插電、熄屏休眠時的網路與 CPU 限制；是否核准由系統設定決定。
- **任務選單**：可複製來源連結、手動選格式或轉文字；尚未開始或已結束的劇集可修正記錄資訊，已建立的檔案不會搬動。
- **引擎線上更新**：yt-dlp 可在 app 內更新，平台改版時不必重裝。

### 語音轉文字（逐字稿）

- **三種來源**：分享本機**影片 / 聲音檔**、分享**影片連結**（自動取音訊轉錄）、或有字幕的 **YouTube**（直接抓字幕、秒出，跳過辨識）。
- **兩種引擎**（設定可切）：
  - **裝置端（預設）**：whisper.cpp，**完全離線、免金鑰、隱私**；可選 `base`（快）/ `small`（較準）模型，首次使用時下載。
  - **雲端**：OpenRouter（**自備 API 金鑰**），速度與中文準度更佳。
- **語言**：多語自動偵測，中文自動轉**台灣正體**；可在設定**鎖定主要語言**，避免無人聲片頭被誤判。
- **背景進行**：通知顯示進度、可中止，中斷後重新開啟 app 可由斷點接續；完成後可**複製 / 分享**，結果頁標示這次用的引擎與模型，並有「**轉錄記錄**」清單。

### 取出聲音

- 分享**影片**時選「**取出聲音**」，會**無損**抽出原音軌存成 `.m4a`（保留原音質、不重新編碼），存到你的下載位置。

## 使用

1. **下載**：在任一 app 點分享 → media-dler；一般來源依設定使用一鍵或彈窗模式，支援來源的劇集播放頁直接加入排程。
2. **選集**：分享支援的劇集首頁，選擇同一線路的集數後按「**加入排程**」。
3. **轉逐字稿**：分享影片 / 聲音檔 → 選「**轉成文字**」；分享連結後可選「**轉文字**」，也可從下載任務選單啟動。
4. **取出聲音**：分享影片 → 選「**取出聲音**」。
5. 設定裡可切換轉錄引擎 / 語言 / 模型，雲端金鑰也在設定貼上。

## 注意與限制

- **平台支援度取決於 yt-dlp**：下載失敗先更新引擎（設定 → 下載引擎 → 更新 yt-dlp），YouTube 尤其常需更新。Threads 影片可下載，**純圖 / 多圖貼文不支援**；IG / FB 私人貼文等需登入，目前僅支援公開內容。
- **雲端轉錄需自備金鑰**：在設定貼上你的 OpenRouter 金鑰（**只存在裝置本機，不內建於 app、不隨版散布**）。按音訊**時長**計費，建議用 `openai/whisper-large-v3-turbo`（最便宜也最穩定）。
- **裝置端模型首次需下載**（`base` ~142MB / `small` ~466MB），非 Wi-Fi 會先詢問；中階手機上 `small` 可能慢於即時，中文準度低於雲端。
- 下載總量未知時顯示已下載量或片段數；封裝與儲存以處理階段顯示。
- **未插電熄屏下載**：請先在「設定 → 背景下載」允許排除電池最佳化；部分手機另有 app 背景執行限制，需在系統電池設定調整。排除最佳化不代表程序不會被系統停止；Android 15 以上仍有背景資料同步服務的時間限制，中斷後可開啟 app 恢復排程。
- 請尊重各平台服務條款與著作權，只下載 / 轉錄你有權保存的內容。
